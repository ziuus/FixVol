# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

FixVol takes security seriously. If you discover a security vulnerability within FixVol, please report it via GitHub Security Advisories or open a confidential issue.

FixVol has no network connections, telemetry, or remote servers, so vulnerabilities are typically limited to local Android IPC or permission scoping.
